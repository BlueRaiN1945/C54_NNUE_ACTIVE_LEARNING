# C54 iterative overnight baseline  2026-09-21

This directory records a compact analysis snapshot of the active
C54 NNUE iterative-training system.

The original live training run remained on BigPC and was not modified
while this snapshot was created.

The full training run was approximately 197 GB and is intentionally
not stored in Git.

Included here are:

- the iterative overnight orchestrator;
- repository/environment snapshot information;
- state snapshots;
- generation/champion manifests;
- the exact upstream nnue-pytorch commit needed to reconstruct
  the training-code baseline.

Large NNUE networks, SQLite mining databases, generation directories,
training corpora and other generated artifacts are intentionally
excluded.
